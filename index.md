# Genie Agent — Demo OKF Bundle

A demonstration bundle in the Open Knowledge Format (OKF) v0.2, published by
Genie Agent LLC under CC BY 4.0. It documents the services Genie Agent offers,
the process that delivers them, and the policies that govern them, drawn from
the public website at genieagent.net. It shows how markdown links turn a
folder of files into a navigable knowledge graph that the Genie Agent (GA)
Cortex plugin can search, read, and traverse.

Status: published. Every concept is verified stable by Victor Titarchuk,
Founder and Head Librarian, on 2026-11-15.
