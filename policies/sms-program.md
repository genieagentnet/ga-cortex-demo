# Overview

Genie Agent sends text messages only in connection with bookings arranged
through Sam, the Genie Voice Assistant persona of the
[Voice Agent](/services/voice-agent.md) service.[^genieagent-sms-terms]

# The program

1. Three kinds of texts only: a booking confirmation when an appointment is booked, one reminder the day before the appointment, and a callback confirmation when a caller asks for a callback.
2. Consent is given during the phone conversation, when Sam confirms the booking and the caller confirms the mobile number.
3. A caller receives only the texts that match the booking or callback they arranged. There are no marketing texts, no purchased lists, and no cold texts.
4. Message and data rates may apply. Reply STOP to opt out; a STOP ends texting to that number. Reply HELP for help.
5. Questions go to hello@genieagent.net.
