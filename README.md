# Genie Agent Cortex Demo Bundle

A demonstration knowledge bundle in the Open Knowledge Format (OKF) v0.2,
published by Genie Agent LLC. It documents the services Genie Agent offers,
the process that delivers them, and the policies that govern them, drawn from
the public website at https://genieagent.net.

The bundle shows how plain Markdown files with structured frontmatter and
cross-links form a knowledge graph that the Genie Agent (GA) Cortex plugin
for Claude Code can search, read, and traverse: ask a question, and the
answer is assembled from these concepts with their sources cited.

## Contents

1. company: the Genie Agent overview.
2. services: AI Readiness Audit, Voice Agent, Lead Capture + CRM, and plans and pricing.
3. process: how an engagement runs, in four steps.
4. runbooks: escalation and handoff.
5. policies: the SMS program and data security.
6. industries, decisions, metrics, support: the sectors served, the founding service decision, the response-time measures, and how to get support.
